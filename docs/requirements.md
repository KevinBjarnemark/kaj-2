# Requirements

### 📣 `Minimum krav` (individuellt)
- ❕ Måste kunna förklara koden     
- ❕ Måste kunna svara på frågor som rör tekniska lösningar    

### 📣 `Minimum krav` (grupp)
- ✔️ Inga kommentarer i koden      
- ✔️ Man ska kunna köra POST requests mot Apiet för att spara data i databasen    
- ✔️ Mins en container   
- ✔️ Ett API i Spring Boot i backenden    
- ✔️ (klar, men ej testad än) Minst en docker container (MySQL)       
- ✔️ Apiet måste kunna exponera data på t ex localhost:8080     
- ✔️ API (Spring Boot)      
    - ✔️ `POST` requests för att spara data i databasen   
    - ✔️ `CRUD` operationer mot MySql databasen  
### 📣 `Kursmål`   
- **Kunskaper**
    - ❕ Redogöra för utveckling av webbapplikationer med HTML, CSS och JavaScript
    - ❕ Redogöra för olika ramverk och plattformar för utveckling av webbapplikationer
    - ❕ Redogöra för terminologi inom utveckling av webbapplikationer på engelska 
- **Färdigheter**
    - ❕ Tillämpa HTML, CSS och JavaScript för att utveckla webbapplikationer
- **Kompetenser**
    - ❕ Självständigt och med säkerhet kunna bedöma olika metoder för att utveckla webbapplikationer
